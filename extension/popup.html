NOTA Labeling Organizer

Enabled

Current version:

  1. Open Labeling, search a part (for example ciga or phone), then expand a clip such as #01.
  2. auto_load_img: preload the current and next unfinished part, with a combined image counter. Keep editing while images load. When the first part is fully Done, its cache is released and the next part loads. Stop pauses; click auto_load_img to resume missing images.
  3. A / D: previous / next visible frame. Shift+A / Shift+D: move 10 frames. Space: play / pause the visible list.
  4. Timeline lock: click the padlock beside the bottom timeline to block accidental clicks/drags. Click again to unlock. A / D, Space, and sidebar frame selection still work; the lock is remembered after reload.
  5. F: toggle Done / In progress. Each clip also has status buttons that update every frame in it.
  6. Done all: tick the checkbox below a part's frame count to mark its entire current-label part Done; untick to set all frames In progress. It follows scrolling and shows save progress. A dash means partially Done.
  7. N: create a box with two corner clicks (clicks in the black margin snap to the image edge), or draw a seatbelt polygon. M: draw an erase region; close it with a right-click or a click on its first point. Esc: exit.
  8. R / Delete / Backspace: delete the selected bounding box(es). Select a box first; holding R does not repeat deletion. On seatbelt, R still accepts the SAM3 preview.
  9. Ctrl+B: repeat an edit across previous / next frames. Enter a count or end. The source frame is excluded and Done targets are skipped.
  10. Copy boxes: copying a selected box replaces matching boxes and keeps other objects; a missing match adds a box. Copying all boxes replaces the target box list.
  11. Body / hand / eye box: X deletes all boxes; 1 / 2 delete the leftmost / rightmost box. C replaces current boxes with all boxes from the nearest earlier frame of the same label that has boxes, skipping empty frames. Shift+X / Shift+C also advance one frame.
  12. Body / hand / eye box: Ctrl+C / Ctrl+V copy / paste, V marks target frames, Ctrl+B repeats the latest operation, and Z undoes it, including an entire batch.
  13. Any bbox edge: double-click the middle handle of the top, bottom, left, or right edge, then drag. Ctrl+B changes only that edge on existing matching boxes; it never adds a duplicate. Z undoes the edit or batch.
  14. Seatbelt SAM3: left-click (+), right-click (−). When the green preview is ready, press R or Enter to add it; Shift+Enter subtracts it. Ctrl+B defaults to the latest change only.
  15. Seatbelt Z: undo the last polygon point or the latest mask edit on this frame. Esc / Cancel clears pending edits; saved edits require Undo.
  16. Eye 15pt: drag inside the dashed box to move; Ctrl + drag to rotate; drag edge / corner handles to resize. K toggles eye points or seatbelt mask visibility.
  17. Reopen Done frames: on labels other than body/hand/eye boxes, select Done frames with V, then Ctrl+B → Set In progress. Existing annotations stay.

On macOS, Cmd+B and Cmd+C/V also work. Shortcuts apply outside text fields. Search and grouping only change the interface; edits and status actions save to DMS.
